# MONTAS · Организатор

Отдельный демонстрационный сайт: https://supervasek38.github.io/organizer/

Этот репозиторий содержит готовую Flutter Web-сборку кабинета организатора и каталога мероприятий в `site/` и собственный workflow Pages. В шапке доступны «Кабинет организатора» и «Каталог мероприятий». Каталог и детальные страницы перенесены из личного кабинета; остальные разделы MONTAS не подключены. Исходники поддерживаются в проекте MONTAS; его история Git сюда не переносится.

## Первая публикация

1. Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. Actions → **Deploy Organizer to GitHub Pages** → Run workflow → **main**.
3. После успешного запуска открыть https://supervasek38.github.io/organizer/.

Публикация запускается вручную. Push в `montas` никак не обновляет этот сайт; push в этот репозиторий сохраняет новую сборку, затем нужно запустить workflow.

## Обновление из исходного проекта

В PowerShell, из папки исходного MONTAS:

```powershell
.\scripts\export-organizer.ps1 -RepositoryPath 'C:\Users\1\Documents\Codex\2026-10-19\new-chat\organizer'
Set-Location -LiteralPath 'C:\Users\1\Documents\Codex\2026-10-19\new-chat\organizer'
git status --short
git add site
git commit -m "Update organizer demo"
git push origin main
```

Затем запустить workflow из Actions. Для другой папки клонирования укажите её в `RepositoryPath`. При необходимости скрипт принимает полный путь к Flutter через `-Flutter` и Git через `-Git`. Скрипт собирает профиль `ORGANIZER_ONLY=true` с базовым адресом `/organizer/`, проверяет репозиторий назначения и заменяет только каталог сгенерированного сайта `site/`.

## Ограничения демо

Тестовые события и участники загружаются при открытии. Изменения, загруженные материалы и уведомления живут в памяти текущей вкладки и сбрасываются при перезагрузке. Реальных рассылок, оплаты, серверной авторизации и синхронизации с полным прототипом нет. Доступ к полному сайту MONTAS по его собственному адресу остаётся независимым.

## Обновлённый кабинет мероприятий

В «Моих мероприятиях» кнопка «Управление событием» открывает рабочую страницу: Обзор, Страница события, Билеты, Участники, Материалы, Уведомления, Статистика.

- До шести форматов участия с отдельной вместимостью и демонстрационной ценой; дополнительные форматы в черновике можно изменять и удалять.
- У опубликованного события можно добавить новый формат; исходные условия записавшихся участников сохраняются.
- Поиск участников и фильтры записавшихся и отменивших участие.
- Статистика по регистрациям, отменам и заполненности, без финансовых операций.
- Предпросмотр страницы с блоками «Для кого», «Что получите», «Как подготовиться».
- Материалы и уведомления сгруппированы по событию.

Основные сущности — событие, формат участия, регистрация, материал, уведомление. Черновик и отмена являются состояниями; статистика рассчитывается из данных. Платежи, выплаты, промоутеры и схемы залов не добавляются.

## Демонстрация каталога

1. В шапке выберите «Каталог мероприятий»: поиск, фильтры, карточки и сохранённые события.
2. Откройте событие: описание, программа, площадка, форматы участия и демо-регистрация.
3. После записи переключитесь в «Кабинет организатора» → Участники нужного события. Запись сразу появится в списке.
4. Созданное и опубликованное организатором мероприятие появляется в этом же каталоге. Кнопка «Открыть как пользователь» открывает его детальную страницу.

Оба режима используют общие данные текущей вкладки. Перезагрузка сбрасывает изменения. Переключение режимов сохраняет состояние кабинета организатора.
